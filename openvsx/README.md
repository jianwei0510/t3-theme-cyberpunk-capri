# Cyberpunk Capri

A pink, crimson, and neon green color theme with dark and light variants, for VS Code, T3 Code, and other editors that use Open VSX.

In T3 Code, the two variants import as one theme that follows Light, Dark, or System mode.

This package contains colors only. It includes no images, character art, or logos.
